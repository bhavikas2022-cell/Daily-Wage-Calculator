# Daily Wage Calculator (Daywork)

A React + Vite app to manage employee profiles and calculate daily wages.
Data is saved in the browser (localStorage), so it works fully offline.

**Live site:** https://bhavikas2022-cell.github.io/Daily-Wage-Calculator/

## Run locally (offline)

```bash
npm install
npm run dev
```
Open http://localhost:5173

To test the production build locally:

```bash
npm run build
npm run preview
```

## Deploy

Every push to `main` is built and published to GitHub Pages automatically
(see `.github/workflows/deploy.yml`).
